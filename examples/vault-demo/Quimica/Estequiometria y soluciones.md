# Estequiometría y soluciones

## El mol

$1\,\text{mol} = 6,022 \times 10^{23}$ entidades (número de Avogadro).

Masa molar $M$ (g/mol) = masa de 1 mol.

$n = \frac{m}{M}$  (mol = gramos / masa molar)

## Reacciones

Ecuación balanceada: mismos átomos a cada lado.

$$aA + bB \to cC + dD$$

Reactivo limitante: el que se gasta primero.

Rendimiento: $\% = \frac{\text{obtenido}}{\text{teórico}} \times 100$

## Soluciones

Concentración molar: $C = \frac{n}{V}$ (mol/L)

Dilución: $C_1V_1 = C_2V_2$

Normalidad, molalidad, fracción molar para casos especiales.

Ver [[Álgebra lineal]] cuando hay sistemas de reacciones acopladas.
